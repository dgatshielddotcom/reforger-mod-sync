REFORGER MOD SYNC

Windows 10/11, .NET Framework 4.8. No installer.
Made for personal use; JSOTF is preselected, but you can pick any server.

1. Open ReforgerModSync.exe and Browse to your addons folder.
2. Enter a server name and click Find server, or paste a ReforgerMods link/UUID.
3. Check the server and preview. Close Reforger and Workbench.
4. Click Delete extra mods and confirm.

Deleting uses the Recycle Bin. Delete permanently frees space immediately
and can't be undone.

Disable extras keeps files in a separate folder. Restore disabled brings
those files back. Disabling doesn't free space.

Import JSON accepts a mod list or server config. Get the complete list,
including dependencies, from the server admin; the app can't verify it.
Confirm [] only for a known vanilla server.

Versions are ignored. Join the server in Reforger to get missing mods and
the required versions. Unknown folders, including saves, stay put.

Download, source and build/test instructions:
https://github.com/dgatshielddotcom/reforger-mod-sync
